## 交互原则

### 核心理念

1. **低频但确定**
   - 用户不是每天打开
   - 但一打开就能明确知道该干嘛

2. **记录 ≠ 操作**
   - 记录资产是快照行为

3. **看清楚优先于算清楚**
   - 相对变化 > 绝对数值

4. **永远不打断用户**
   - 不强提醒、不催促、不制造焦虑

## 一、【总览页】交互设计

### 页面定位
> 用户打开 App 的"第一反应页"
> 这是一个"确认 + 行动入口"页面，而不是分析页面

### 页面结构

```
┌─────────────────────────────────┐
│  📱 总览页                       │
├─────────────────────────────────┤
│                                 │
│  [1] 当前资产快照                │
│  ┌─────────────────────────┐   │
│  │  总资产                  │   │
│  │  ¥ 285,600              │   │
│  │                         │   │
│  │  最近一次记录: 2天前      │   │
│  │  距离上一次记录: 7天      │   │
│  └─────────────────────────┘   │
│                                 │
│  [2] 核心趋势区                 │
│  ┌─────────────────────────┐   │
│  │   📈 总资产趋势折线       │   │
│  │                         │   │
│  │   [周] [月]             │   │
│  └─────────────────────────┘   │
│                                 │
│  [3] 快照入口                   │
│  ┌─────────────────────────┐   │
│  │   + 记录一次资产          │   │
│  │   只需几分钟              │   │
│  └─────────────────────────┘   │
│                                 │
│  [4] 资产结构速览               │
│  ┌─────────────────────────┐   │
│  │  流动资金    45%  →      │   │
│  │  投资资产    40%  →      │   │
│  │  长期资产    15%  →      │   │
│  └─────────────────────────┘   │
│                                 │
└─────────────────────────────────┘
```

### 1️⃣ 顶部：当前资产快照

**展示内容**:
- 总资产（大数字，48px，深蓝色）
- 辅助信息：
  - 最近一次记录时间
  - 距离上一次记录：X 天

**交互**:
- 点击总资产数字 → 进入「分析页」
- 长按数字 → 隐藏/显示金额（隐私模式）

**状态处理**:
- 如果从未记录：显示「开始记录第一次资产」
- 如果超过14天未记录：显示提示「已经X天未记录」

### 2️⃣ 核心趋势区（只放一个图）

**默认展示**: 总资产趋势折线图

**周期切换**:
```
[ 周 ]  [ 月 ]
```

**交互要点**:
- 手指滑动 → 显示对应时间点资产值
- 不展示太多指标，只展示变化
- 点击图表 → 进入「分析页」查看详情

**空状态**:
- 如果数据少于2个快照：显示「再记录几次，就能看到趋势了」

### 3️⃣ 快照入口（最重要的操作）

**视觉设计**:
```
┌─────────────────────────────┐
│    + 记录一次资产            │
│    只需几分钟                │
└─────────────────────────────┘
```

**交互逻辑**:

1. **点击后进入记录流程**:
   ```
   步骤1: 选择记录方式
   ┌─────────────────────┐
   │ ○ 快速记录          │  ← 默认选中
   │   继承上次数据       │
   │                     │
   │ ○ 完整记录          │
   │   从头开始填写       │
   └─────────────────────┘

   步骤2: 填写资产（分类展示）
   ┌─────────────────────┐
   │ 💵 现金              │
   │   CNY: 5,000  [编辑] │
   │   USD: 1,000  [编辑] │
   │   + 添加币种         │
   ├─────────────────────┤
   │ 🏦 银行账户          │
   │   DBS: 15,000 [编辑] │
   │   + 添加账户         │
   ├─────────────────────┤
   │ 📈 证券              │
   │ ₿ 加密资产           │
   │ 💳 日常支付账户       │
   └─────────────────────┘

   步骤3: 添加备注（可选）
   ┌─────────────────────┐
   │ 📝 本次变化说明      │
   │ [输入框]            │
   │ 例如：工资到账、      │
   │ 股票盈利等           │
   └─────────────────────┘

   步骤4: 保存
   [ 取消 ]      [ 保存快照 ]
   ```

2. **快速记录模式（推荐）**:
   - 默认继承上一次快照
   - 用户只改变化项
   - 支持快速保存

3. **完整记录模式**:
   - 从头开始填写所有资产
   - 适合首次使用或资产大幅变化

**设计要点**:
- 入口明确、低干扰
- 文案强调：只需几分钟
- 按钮样式突出但不刺眼

### 4️⃣ 资产结构速览（轻量）

**展示内容**:
```
流动资金    45%   →
投资资产    40%   →
长期资产    15%   →
```

**交互**:
- 只显示占比，不显示细节
- 点击任一项 → 跳转到「分析页」的对应模块

**设计要点**:
- 简洁的横向进度条
- 使用深浅不同的蓝色
- 右侧箭头暗示可点击

## 二、【数据分析页】交互设计

### 页面定位
> 用户"坐下来看的地方"
> 按"问题"组织内容，而不是按图表类型

### 页面结构

├─────────────────────────────────┤

│  [顶部] 分析维度选择             │

│                                 │
├─────────────────────────────────┤
│                                 │
│  [模块一] 资产变化总结           │
│  ┌─────────────────────────┐   │
│  │  本周期总资产            │   │
│  │  ¥ 285,600             │   │
│  │  + ¥ 8,500 (+3.1%)     │   │
│  │                         │   │

│  │  "本月资产主要由          │   │
│  │   【证券资产上涨】推动"    │   │
│  └─────────────────────────┘   │
│                                 │
│  [模块二] 变化来源拆解           │
│  ┌─────────────────────────┐   │
│  │   📊 瀑布图 / 条形图      │   │
│  │                         │   │

│  [模块三] 结构变化               │
│  ┌─────────────────────────┐   │
│  │   本期 vs 上期           │   │
│  │   [对比条形图]           │   │

│                                 │

### 1️⃣ 顶部：分析维度选择

**周期切换**:
```
[ 周 ]  [ 月 ]  [ 季度 ]
```

**对比对象**:
```
○ 上一周期（默认）
○ 自定义周期
```

**交互**:
- 切换周期后，所有图表联动更新
- 自定义周期：弹出日期选择器

### 2️⃣ 核心分析模块（按"问题"组织）

#### 模块一：资产变化总结

**展示内容**:
- 本周期总资产
- 变化值：+X / -X
- 变化百分比
- AI 一句话分析（接入大模型 API）

**交互**:
- 点击"AI 分析" → 展开详细分析

**示例**:
```
本月资产：¥ 285,600
+ ¥ 8,500 (+3.1%)

💬 AI 分析：
"本月资产主要由【证券资产上涨】推动,
其中股票账户增长了 ¥10,000,
但现金支出了 ¥2,000"
```

#### 模块二：变化来源拆解

**推荐图表**: 瀑布图 / 条形图

**交互要点**:
- 按资产类别展示贡献
- 点击某一项 → 查看该类别详情

**示例**:
```
上期总资产: ¥277,100
  投资资产  + ¥10,000
  现金      - ¥2,000
  Crypto    + ¥500
本期总资产: ¥285,600
```

#### 模块三：结构变化

**本期 vs 上期对比**:
```
资产类别      本期    上期    变化
流动资金      45%     48%    -3%
投资资产      40%     37%    +3%
长期资产      15%     15%     0%
```

**交互重点**:
- 强调「占比变化」
- 不强调绝对金额
- 颜色区分增减（深蓝/中灰）

#### 模块四：记录备注回顾

**展示方式**: 时间线形式

```
📝 2024-01-15
"年终奖到账，投入基金"

📝 2024-01-08
"股票止盈，转入定期"

📝 2024-01-01
"新年首次记录"
```

**交互**:
- 点击备注 → 查看当时的完整快照
- 长按 → 编辑/删除备注

## 交互检查清单

设计每个交互流程时，确保：

- [ ] 操作路径清晰，不超过3步
- [ ] 有明确的视觉反馈
- [ ] 错误状态有友好提示
- [ ] 空状态有引导操作
- [ ] 重要操作有二次确认
- [ ] 支持手势操作（移动端）
- [ ] 响应速度 < 200ms
- [ ] 动效克制，不过度
- [ ] 文案简洁，符合用户心智模型
- [ ] 不打断用户，不强制引导
