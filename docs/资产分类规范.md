## 资产分类总览

| 资产大类 | 细分类别 | 备注 |
|---------|---------|------|
| 现金 | 本币、外币 | 不同币种现金 |
| 银行账户 | 银行活期存款、定期存款 | 不同银行、不同币种 |
| 证券 | 股票、ETF、基金、债券 | 不同地区交易所 |
| 加密资产 | 主流加密货币 | 多币种支持 |
| 日常支付账户 | 微信、支付宝、PayLah | 高频支付工具 |

## 1️⃣ 现金

### 细分类别
- 本币
- 外币

### 适用场景
用于记录你直接持有、可随时使用的现金资产。

### 用户需要填写

| 字段 | 类型 | 说明 | 必填 |
|-----|------|------|------|
| 币种 | 下拉选择 | 如 CNY / USD / HKD | ✅ |
| 当前金额 | 数字 | 当前持有的现金数量 | ✅ |
| 备注 | 文本 | 可选说明 | ❌ |

### 交互说明

- ✅ 本币与外币分别记录，系统会统一折算为基准货币
- ✅ 支持用户自动填写符合要求对应的外币缩写
- ✅ 调取 API 自动获取汇率，以天为单位进行更新汇率
- ✅ 基准货币总览同步更新
- ✅ 多个币种可同时存在

### 设计意图

> 帮助你清楚知道「不依赖任何机构，我现在手里有多少现金」。

### 数据示例

```json
{
  "assetType": "cash",
  "items": [
    {
      "currency": "CNY",
      "amount": 5000,
      "note": "日常备用金"
    },
    {
      "currency": "USD",
      "amount": 1000,
      "note": "美元现金"
    }
  ]
}
```

## 2️⃣ 银行账户

### 细分类别
- 银行活期存款
- 定期存款

### 适用场景
用于记录存放在银行体系内的资金。

### 用户需要填写

| 字段 | 类型 | 说明 | 必填 |
|-----|------|------|------|
| 银行账户名称 | 文本 | 如 DBS、工行、OCBC | ✅ |
| 存款类型 | 单选 | 活期 / 定期 | ✅ |
| 币种 | 下拉选择 | 如 CNY / USD / SGD | ✅ |
| 当前余额 | 数字 | 账户当前余额 | ✅ |
| 备注 | 文本 | 可选说明 | ❌ |

### 交互说明

- ✅ 每个银行账户作为一条独立记录
- ✅ 定期存款只记录当前本金或估值，不要求拆分利息
- ✅ 支持多银行、多币种并存
- ✅ 自动汇率转换

### 设计意图

> 区分"随时可用的钱"和"相对锁定的钱"，更好理解资金流动性。

### 数据示例

```json
{
  "assetType": "bank",
  "items": [
    {
      "bankName": "DBS",
      "depositType": "current",
      "currency": "SGD",
      "balance": 15000,
      "note": "工资卡"
    },
    {
      "bankName": "工商银行",
      "depositType": "fixed",
      "currency": "CNY",
      "balance": 100000,
      "note": "1年期定期"
    }
  ]
}
```

## 3️⃣ 证券

### 细分类别
- 股票
- ETF
- 基金
- 债券

### 适用场景
用于记录你在证券市场中的投资资产。

### 用户需要填写

| 字段 | 类型 | 说明 | 必填 |
|-----|------|------|------|
| 投资账户名称 | 文本 | 如某券商名称 | ✅ |
| 投资类型 | 多选 | 股票/ETF/基金/债券 | ✅ |
| 币种 | 下拉选择 | 如 CNY / USD / HKD | ✅ |
| 当前账户总市值 | 数字 | 整个账户的市值 | ✅ |
| 备注 | 文本 | 可选说明 | ❌ |

### 交互说明

- ✅ 以「账户维度」记录，而非单个标的
- ❌ 不要求填写持仓明细
- ✅ 市值可手动填写，反映你当下的整体情况
- ✅ 支持多币种资产

### 设计意图

> 关注"这部分资产现在值多少钱"，而不是短期波动细节。

### 数据示例

```json
{
  "assetType": "securities",
  "items": [
    {
      "brokerName": "老虎证券",
      "securityTypes": ["stock", "etf"],
      "currency": "USD",
      "totalMarketValue": 50000,
      "note": "美股账户"
    },
    {
      "brokerName": "支付宝",
      "securityTypes": ["fund"],
      "currency": "CNY",
      "totalMarketValue": 80000,
      "note": "基金定投"
    }
  ]
}
```

## 4️⃣ 加密资产

### 细分类别
- 主流加密货币（BTC、ETH、USDT等）

### 适用场景
用于记录加密资产及相关平台中的资金。

### 用户需要填写

| 字段 | 类型 | 说明 | 必填 |
|-----|------|------|------|
| 平台或钱包名称 | 文本 | 如交易所、钱包名称 | ✅ |
| 加密货币种类 | 文本 | 如 BTC / ETH / USDT | ✅ |
| 当前数量或市值 | 数字 | 持有数量或当前市值 | ✅ |
| 汇率 | 自动/手动 | 自动获取或手动填写 | ✅ |
| 备注 | 文本 | 可选说明 | ❌ |

### 交互说明

- ✅ 加密资产单独作为一个资产大类展示
- ✅ 支持多币种同时记录
- ✅ 折算为基准货币后参与总资产统计
- ✅ 通过 API 调取实时汇率，按天更新

### 设计意图

> 帮助你随时看清加密资产在整体资产中的占比与变化。

### 数据示例

```json
{
  "assetType": "crypto",
  "items": [
    {
      "platform": "Binance",
      "cryptoType": "BTC",
      "amount": 0.5,
      "marketValue": 25000,
      "exchangeRate": "auto",
      "note": "长期持有"
    },
    {
      "platform": "MetaMask",
      "cryptoType": "ETH",
      "amount": 10,
      "marketValue": 30000,
      "exchangeRate": "auto",
      "note": "钱包资产"
    }
  ]
}
```

## 5️⃣ 日常支付账户

### 细分类别
- 微信
- 支付宝
- PayLah

### 适用场景
用于记录高频日常支付中使用的钱包余额。

### 用户需要填写

| 字段 | 类型 | 说明 | 必填 |
|-----|------|------|------|
| 支付账户类型 | 单选 | 微信/支付宝/PayLah | ✅ |
| 当前余额 | 数字 | 账户当前余额 | ✅ |
| 备注 | 文本 | 可选说明 | ❌ |

### 交互说明

- ✅ 每个支付工具单独记录
- ✅ 默认使用基准货币
- ✅ 金额变化频繁，但记录成本低

### 设计意图

> 让"零散但常用的钱"不再被忽略。

### 数据示例

```json
{
  "assetType": "payment",
  "items": [
    {
      "paymentType": "wechat",
      "balance": 3000,
      "note": "日常消费"
    },
    {
      "paymentType": "alipay",
      "balance": 5000,
      "note": "备用金"
    },
    {
      "paymentType": "paylah",
      "balance": 500,
      "note": "新加坡日常"
    }
  ]
}
```

## 资产分类使用建议

### 1. 记录频率建议

| 资产类型 | 建议记录频率 | 原因 |
|---------|------------|------|
| 现金 | 每周/每月 | 变化相对稳定 |
| 银行账户 | 每周/每月 | 变化相对稳定 |
| 证券 | 每周/每月 | 关注市值趋势 |
| 加密资产 | 每周 | 波动较大，建议更频繁记录 |
| 日常支付账户 | 每周/每月 | 金额较小，可灵活记录 |

### 2. 币种处理原则

- 所有资产最终统一折算为**基准货币**
- 基准货币在「我的」页面设置
- 汇率每天自动更新（通过 API）
- 用户可选择是否启用自动汇率

### 3. 资产分组展示

在数据分析页面，资产将按以下分组展示：

```
总资产
├── 流动资产（现金、日常支付账户、银行活期）
├── 投资资产（证券、加密资产）
└── 定期资产（银行定期存款）
```
