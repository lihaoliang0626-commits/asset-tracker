## 核心概念

### 资产快照（Asset Snapshot）

资产快照是用户在某个时间点记录的完整资产状态。这是整个系统的核心数据单元。

**设计原则**:
- 快照是不可变的（immutable）
- 每次记录都创建新快照，不修改历史快照
- 快照之间相互独立，便于对比分析

## 数据模型

### 1. 资产快照（Snapshot）

```typescript
interface Snapshot {
  id: string;                    // 快照唯一ID
  userId: string;                // 用户ID

  note?: string;                 // 用户备注

  updatedAt: number;             // 更新时间
}
```

### 2. 资产分组（AssetGroup）

```typescript
interface AssetGroup {
  type: AssetType;               // 资产大类

type AssetType =

  | 'securities'                 // 证券
  | 'crypto'                     // 加密资产
```

## 数据计算逻辑

### 1. 总资产计算

```typescript
function calculateTotalAsset(snapshot: Snapshot): number {
  return snapshot.assets.reduce((total, group) => {
    return total + group.totalValue;
  }, 0);
}
```

### 2. 资产占比计算

```typescript
function calculatePercentage(
  groupValue: number,
  totalAsset: number
): number {
  if (totalAsset === 0) return 0;
  return (groupValue / totalAsset) * 100;
}
```

### 3. 汇率转换

```typescript
function convertToBaseCurrency(
  amount: number,
  fromCurrency: string,
  baseCurrency: string,
  exchangeRates: ExchangeRate[]
): number {
  if (fromCurrency === baseCurrency) return amount;

  const rate = exchangeRates.find(
    r => r.fromCurrency === fromCurrency && r.toCurrency === baseCurrency
  );

  if (!rate) {
    throw new Error(`Exchange rate not found for ${fromCurrency} -> ${baseCurrency}`);
  }

  return amount * rate.rate;
}
```

### 4. 变化计算

```typescript
function calculateChange(
  currentSnapshot: Snapshot,
  previousSnapshot: Snapshot
): {
  absoluteChange: number;
  percentageChange: number;
} {
  const current = currentSnapshot.totalAsset;
  const previous = previousSnapshot.totalAsset;

  const absoluteChange = current - previous;
  const percentageChange = previous === 0
    ? 0
    : (absoluteChange / previous) * 100;

  return { absoluteChange, percentageChange };
}
```

### 5. 贡献分析

```typescript
function analyzeContributions(
  currentSnapshot: Snapshot,
  previousSnapshot: Snapshot
): {
  assetType: AssetType;
  change: number;
  changePercentage: number;
}[] {
  const contributions: Map<AssetType, number> = new Map();

  // 计算每个资产类型的变化
  for (const currentGroup of currentSnapshot.assets) {
    const previousGroup = previousSnapshot.assets.find(
      g => g.type === currentGroup.type
    );

    const previousValue = previousGroup?.totalValue || 0;
    const change = currentGroup.totalValue - previousValue;

    contributions.set(currentGroup.type, change);
  }

  // 转换为数组并计算百分比
  const totalChange = currentSnapshot.totalAsset - previousSnapshot.totalAsset;

  return Array.from(contributions.entries()).map(([assetType, change]) => ({
    assetType,
    change,
    changePercentage: totalChange === 0 ? 0 : (change / Math.abs(totalChange)) * 100
  }));
}
```

## 数据验证

### 快照验证规则

```typescript
function validateSnapshot(snapshot: Snapshot): ValidationResult {
  const errors: string[] = [];

  // 1. 必填字段检查
  if (!snapshot.id) errors.push('Snapshot ID is required');
  if (!snapshot.userId) errors.push('User ID is required');
  if (!snapshot.baseCurrency) errors.push('Base currency is required');

  // 2. 总资产必须非负
  if (snapshot.totalAsset < 0) {
    errors.push('Total asset cannot be negative');
  }

  // 3. 资产组验证
  for (const group of snapshot.assets) {
    if (group.totalValue < 0) {
      errors.push(`Asset group ${group.type} value cannot be negative`);
    }

    // 验证百分比之和
    const sumOfPercentages = snapshot.assets.reduce(
      (sum, g) => sum + g.percentage, 0
    );

    if (Math.abs(sumOfPercentages - 100) > 0.01) {
      errors.push(`Sum of percentages must be 100, got ${sumOfPercentages}`);
    }
  }

  // 4. 汇率检查
  for (const group of snapshot.assets) {
    for (const item of group.items) {
      if ('exchangeRate' in item && item.exchangeRate <= 0) {
        errors.push(`Invalid exchange rate for ${item.name}`);
      }
    }
  }

  return {
    valid: errors.length === 0,
    errors
  };
}

interface ValidationResult {
  valid: boolean;
  errors: string[];
}
```

### 迁移函数

```typescript
interface Migration {
  from: string;
  to: string;
  migrate: (data: any) => any;
}

const migrations: Migration[] = [
  {
    from: '1.0.0',
    to: '1.1.0',
    migrate: (snapshot) => {
      // 迁移逻辑
      return {
        ...snapshot,
        newField: 'default value',
        schemaVersion: '1.1.0'
      };
    }
  }
];

function migrateSnapshot(snapshot: Snapshot): Snapshot {
  let current = snapshot;

  for (const migration of migrations) {
    if (current.schemaVersion === migration.from) {
      current = migration.migrate(current);
    }
  }

  return current;
}
```
