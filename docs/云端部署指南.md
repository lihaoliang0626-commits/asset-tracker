# 云端部署指南

## Supabase

1. 创建 Supabase 项目。
2. 在 SQL Editor 中执行 `supabase/schema.sql`。
3. 在 Authentication 设置中启用 Email 登录。
4. 复制 Project URL 和 anon public key。

## 本地环境

在 `packages/web/.env.local` 中写入：

```bash
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

然后运行：

```bash
pnpm dev:web
```

## Netlify

使用仓库根目录部署。`netlify.toml` 已配置：

- 静态产物目录：`packages/web/dist`
- 函数目录：`netlify/functions`
- `/api/*` 自动转发到 Netlify Functions

需要配置环境变量：

```bash
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
DEEPSEEK_API_KEY=your-deepseek-key
```

`DEEPSEEK_API_KEY` 未配置时，只有 AI 总结不可用，其他资产记录与分析功能不受影响。

## 旧数据导入

旧版本地 IndexedDB 数据需要先在旧版本设置页导出 JSON。登录云端版后进入设置页，使用“导入数据”选择该 JSON 文件，数据会写入当前 Supabase 用户账号。
