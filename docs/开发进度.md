### 2. 工具函数（100% 完成）

**货币工具** (`packages/shared/utils/currency.ts`):

**计算工具** (`packages/shared/utils/calculation.ts`):
- `calculateTotalAsset()` - 计算总资产
- `calculateGroupTotal()` - 计算资产组总值
- `calculatePercentage()` - 计算占比
- `calculateChange()` - 计算资产变化
- `analyzeContributions()` - 贡献分析
- `compareStructure()` - 结构对比
- `buildTrendData()` - 构建趋势数据
- `validateSnapshot()` - 验证快照数据
- `fixSnapshot()` - 修正快照数据

**日期工具** (`packages/shared/utils/date.ts`):
- `generateId()` - 生成唯一ID
- `formatDate()` - 格式化日期
- `daysBetween()` - 计算天数差
- `getStartOfDay()`, `getEndOfDay()` - 获取一天的开始/结束时间
- `getStartOfWeek()`, `getStartOfMonth()`, `getStartOfQuarter()`, `getStartOfYear()` - 获取各周期开始时间
- `getDateRange()` - 获取日期范围
- `getPreviousPeriodRange()` - 获取上一周期范围
- `formatDateRange()` - 格式化时间范围
- `isSameDay()`, `isSameWeek()`, `isSameMonth()` - 时间比较

### 3. 数据存储层（100% 完成）

  - 导入/导出
- `PreferencesStorage` - 应用偏好管理器（localStorage）

**汇率存储** (`packages/shared/storage/exchange-rate.ts`):

  - 删除过期汇率
  - 检查汇率是否最新
  - 统计信息
  - 导入/导出

**分析缓存存储** (`packages/shared/storage/analytics-cache.ts`):
- `AnalyticsCacheStorage` - 分析数据缓存管理器

  - 统计信息
  - 导入/导出

   - 验证函数独立，可复用

4. **性能优化**
