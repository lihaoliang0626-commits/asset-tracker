## 设计理念：简约大气

资产追踪应用采用**简约大气**设计语言，打造清晰、可信、易用的视觉体验：

- 🌫️ **简约克制** - 浅色清爽背景，充足留白，去除装饰
- 📊 **数据优先** - 数字清晰有力，信息层级分明
- 🎯 **易用直观** - 交互清晰，降低认知负担
- 💜 **温和强调** - 紫色点缀，不抢眼但有存在感
- ✨ **大气开放** - 宽松间距，呼吸感强

## 配色方案：简约白紫

### 🎯 设计定位

- **目标用户**: 所有投资理财用户，追求清晰易用
- **使用场景**: 日常查看数据，快速了解资产概况
- **情绪基调**: 清爽、信任、开放、亲切

## 动效规范

```css
/* 标准过渡 */
transition: all 0.2s ease;

/* 快速过渡 */
transition: all 0.15s ease;

/* 慢速过渡 */
transition: all 0.3s ease;
```

### 常用动效

1. **按钮点击** - 微缩放 0.15s
2. **卡片悬停** - 背景色变化 0.2s
3. **页面切换** - 淡入淡出 0.3s
4. **加载状态** - 脉动 2s infinite

## 设计检查清单

- [ ] 背景为浅色（#FFFFFF 或 #F8F8F8）
- [ ] 文本为黑色/深灰
- [ ] 紫色仅用于强调（按钮、选中态、标签）
- [ ] 充足的留白和宽松间距
- [ ] 数字使用等宽字体
- [ ] 卡片有微妙阴影或浅灰边框
- [ ] 按钮悬停有视觉反馈
- [ ] 圆角统一（6-8px）
- [ ] 动效简洁、不过度
- [ ] 响应式适配完整
