## 📊 核心功能展示

### 进度计算

```typescript
// 基础进度
progress = (当前金额 - 起始金额) / (目标金额 - 起始金额) × 100%

// 时间进度
timeProgress = (已过天数 / 总天数) × 100%

// 是否在正轨上
onTrack = progress >= timeProgress × 90%
```

### 趋势预测（EWMA）

```typescript
// 指数加权移动平均
alpha = 0.3  // 平滑系数
ewma = alpha × 当前增长率 + (1 - alpha) × 上期ewma

// 预测到期金额
remainingMonths = (deadline - now) / 30天
predictedAmount = currentAmount + (avgMonthlyGrowth × remainingMonths)

// 预测达成日期
monthsNeeded = remainingAmount / avgMonthlyGrowth
predictedDate = now + (monthsNeeded × 30天)
```

### 状态判断

| 条件 | 状态 |
|------|------|
| 当前金额 ≥ 目标金额 | achieved（已达成）|
| now > deadline 且未达成 | overdue（已过期）|
| 当前金额 < 起始金额 | not_started（尚未开始）|
| 进度 ≥ 时间进度 × 90% | on_track（在正轨上）|
| 进度 < 时间进度 × 90% | behind（落后）|

```
用户创建目标
    ↓
GoalStore.createGoal()
    ↓
保存到 localStorage
    ↓
用户记录新快照
    ↓
SnapshotStore.createSnapshot()
    ↓
useEffect 检测到快照更新
    ↓
GoalStore.refreshProgress()
    ↓
calculateGoalProgress()
    ↓
更新 currentProgress
    ↓
```
