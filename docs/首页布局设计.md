# 首页（概览页）布局设计文档

**版本**: 1.0
**日期**: 2026-01-23
**设计风格**: 简约大气

---

## 设计目标

1. **确认 + 行动入口** - 用户一打开就能确认资产现状并快速记录
2. **最小认知负担** - 只展示必要的核心信息，避免首页变成“列表页”
3. **清晰层级** - 重要信息大而醒目，次要信息克制呈现
4. **可持续使用** - 低频记录场景下的空状态/久未记录提示

---

## 状态与文案规范

### 1. 首次使用（无快照）
- **净资产卡片**: “开始记录第一次资产”
- **趋势区**: “再记录几次，就能看到趋势了”
- **快照入口**: 保持主操作高亮

### 2. 久未记录（>14天）
- **净资产卡片辅助文案**: “已经 X 天未记录”
- **建议**: 不强提醒，仅信息提示

### 3. 隐私模式（金额隐藏）
- **触发**: 长按净资产数字
- **表现**: 金额显示为 “***”

## 响应式适配

### 移动端 (< 640px)
- 保持当前设计
- 左右间距统一为 16px
- 双列卡片间距 8px

### 平板 (641px - 1024px)
- 最大宽度: 640px
- 居中显示
- 左右间距增加到 24px

### 桌面端 (> 1024px)
- 最大宽度: 800px
- 居中显示
- 左右间距 32px
